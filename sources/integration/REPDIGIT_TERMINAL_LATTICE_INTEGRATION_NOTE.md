# Repdigit Harmonic Terminal-Lattice Integration Note

**Source record:** complete derivation v8.1.0  
**Author:** Abhijit Singh

The ten decimal repdigits are the scaled lattice `f_d = 111 d Hz`, with zero and unit terminals, prime-indexed interior harmonics `222, 333, 555, 777`, and composite-indexed interior harmonics `444, 666, 888, 999`. The affine involution `sigma(d)=1-d mod 10` swaps the terminals and every prime index with one composite index. The two sector indicators have identical cyclic Fourier magnitudes. The result is invariant under positive rescaling and therefore does not select 111 Hz as a physical constant.
