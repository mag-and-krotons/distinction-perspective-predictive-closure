# Read this first

I recommend beginning with `COMPLETE_PAPER_SERIES.pdf`, the complete
two-hundred-page research series. The individual papers remain independently
compilable and are indexed in `submissions/INDEX.csv`; the combined volume does
not replace those submission packages.

For the newest integrated result, read
`papers/P17_prime_observer_36_relation_closure/main.pdf`. For the visual
structure of the programme, open `atlas/MASTER_SCIENTIFIC_ATLAS.pdf`.

Before reusing or redistributing a release package, run:

```bash
python scripts/verify_release.py
```

The verifier checks the scientific inventory, source packages, manifests,
checksums, nested archives, and release assets without changing the research
files.
