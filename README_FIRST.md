# Read this first

Release 8.0.2 is the Git- and Zenodo-ready source release.

- Read `COMPLETE_PAPER_SERIES.pdf` for the bound series.
- Use `submissions/INDEX.csv` and the individual ZIPs for field submission.
- Read `papers/P17_prime_observer_36_relation_closure/main.pdf` for the newly integrated theorem.
- Run `python scripts/verify_release.py` before publication.
- Follow `ZENODO_GIT_RELEASE_GUIDE.md` for remote creation, tagging, DOI reservation, and upload.

The combined volume is not a substitute for the individual paper packages.

## Academic-source separation
Raw handwritten research notes are not part of any academic manuscript, paper source archive, individual submission package, or public release asset. Only formal typeset exposition, proofs, data, code, and publication-grade figures are included.
