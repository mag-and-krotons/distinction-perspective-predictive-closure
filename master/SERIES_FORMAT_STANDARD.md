# Abhijit Singh Uniform Academic Series - Format Standard v1.0

## Page and typography

- Page size: A4, 210 x 297 mm.
- Body: NewTX serif, 11 pt, uniform 1.035 line spacing.
- Headings and navigation: Helvetica-compatible sans serif.
- Side margins: 22 mm; top 21 mm; bottom 20 mm.
- Accent: restrained burgundy `#8A2634`; body text remains near-black.

## Mandatory paper sequence

1. Full title page with paper code, version, date, title, subtitle, and author.
2. Dedicated contents page.
3. Dedicated abstract page with keywords, scope/status, citation, and document status.
4. Numbered body sections.
5. References and appendices in the contents.

## Running matter

- Uniform short-title header at left.
- Paper code at right.
- Centred page number in footer.
- No affiliation line.
- Sole author line: Abhijit Singh.

## Scientific objects

- Sections, subsections, parts, theorems, definitions, tables, figures, captions, equations, lists, status callouts, references, and appendices use one shared style file.
- Tables use booktabs spacing and one common row height.
- Figures and tables use left-aligned captions with burgundy labels.
- Claim-status statements use one shaded callout with a burgundy left rule.

## Source rule

Every paper compiles from `main.tex` plus the included `abhijit-research.sty`; no local formatting override is permitted without a recorded exception.
