# Zenodo research publication metadata

The linked Zenodo record is the primary archival record for my complete
research release. It must be classified as **Publication — Other**, not as
software. The papers and scientific atlas are the principal intellectual
objects; code, data, Git history, checksums, and source packages support their
verification and reproducibility.

`.zenodo.json` is the authoritative metadata supplied to the GitHub–Zenodo
integration. `master_record_metadata.json` expresses the same research record
for manual verification of the live Zenodo fields. It is not an instruction to
create a duplicate deposit.

The nineteen files under `individual_records/` are optional templates for
separate paper-level deposits. They should be used only if I deliberately
choose to give an individual paper its own DOI and relate it to the complete
research release.
