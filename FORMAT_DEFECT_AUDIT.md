# Formatting Defect Audit of the Superseded Suite

The superseded edition did not meet a coherent publication standard. The defects were structural, not cosmetic:

1. US Letter output was used while the approved reference manuscript used A4.
2. Generic title matter produced different visual proportions from the approved standard.
3. The front-matter sequence and page density were not controlled as one system.
4. P01 contained manually embedded section numbers in addition to automatic numbering, producing duplicated numbers.
5. P01 produced a duplicated References entry because a manual reference section was followed by an empty bibliography environment.
6. Running headers, heading hierarchy, captions, table spacing, and bibliography typography were not uniform.
7. Global loose line-breaking concealed defects rather than solving them.
8. The combined PDF inherited inconsistent page geometry and missing metadata.

Version 7.0 replaces that nominally shared preamble with one enforced house style and a clean rebuild of every source package.
