# Evidence-Gated Rebuild Sequence

This sequence replaces the false assumption that correcting P02 alone clears the release.

## Gate 0 — Maintain the hold

The current tagged/public release remains a historical record. All repairs occur on new branches. No Zenodo upload/update, GitHub release, journal package, or arXiv source is generated from the quarantined paper set.

## Gate 1 — Repair release infrastructure once

1. Add claim-level in-text citations throughout P00–P17 and the atlas.
2. Add a pinned execution environment and CI that installs dependencies and runs every paper-specific reproduction.
3. Replace file-level source coverage with a claim-to-source-to-artifact ledger.
4. Remove DOI, repository, record-type, and equation placeholders from archival metadata.
5. Separate first-party manuscripts and code from third-party datasets with file-level licenses and provenance.
6. Make the release verifier enforce each paper's required artifacts, not merely compilation, layout, hashes, and ZIP integrity.

## Gate 2 — Recover evidence-heavy packages in parallel

### P02 — Complete numerical quantum instrument

Serialize the numerical effects, raw and physicalized returned states, tomography setting/provenance record, covariance-status statement, Bell-to-computational basis transform, all Kraus operators, all outcome Choi blocks, marked and unmarked Choi matrices, complete spectra, corrected transition law, and one raw-input-to-receipt command.

### P03 — Representation genesis

Recover the full 299+17 test corpus, fixtures, six object classes, two relation classes, 27-row ternary relation table, restart checks, hash-bound transport, ablation/restoration, and a clean-room reproduction.

### P07 — Capacity topology

Implement the actual quota complex, discrete Morse matching, boundary matrices, homology, persistent intervals, and operator-ideal checks.

### P10 — Empirical representation repair

Recover both source studies: raw datasets or lawful provenance, all preprocessing, constructors, frozen split IDs, models, predictions, row-level metrics, uncertainty, leakage controls, ablations, and clean replay.

### P13 — Detector prediction

Recover physical constants, units, cross-sections, stopping laws, optical threshold, efficiency model, numerical integration, sensitivity analysis, uncertainty bands, and the preregistered three-gas protocol.

### P14 — Cosmology

Retain the exact conditional branch, then add current observational data/covariance provenance, likelihood code, priors, residuals, parameter comparison, model comparison, and explicit falsification thresholds.

### P16 — Adaptive predictive system

Either implement the recurrent/sparse/routed architecture and its benchmark, or retitle the unit as a design specification. P03's finite transfer code is not evidence for the full P16 system.

## Gate 3 — Proof-first mathematical papers

### P01

Complete claim-level citations, theorem dependency graph, examples, counterexamples, and an independent proof audit.

### P04–P06

Separate exact theorems from finite patterns. Add assumption ledgers, countermodels, certified root isolation where needed, and paper-specific reproduction packages.

### P08

Expand every RH-equivalence implication into a complete proof with hypotheses and prior-art comparison. Keep the universal estimate explicitly open.

### P09

Provide the exact moving-boundary decomposition, signed sums, first-deletion and path-information objects, failed routes, and specialist review. Retain technical-report status until the live estimate is proved.

### P11–P12

Separate proved formal closure from conditional representation and heuristic physical transfer. Provide proof trees and worked models; keep unquantized or experimentally untested structures open.

### P17

Publish only the finite relation/reporter theorem unless the affine involution, quantum-number interpretation, earlier nine-state correspondence, and frequency realization acquire independent derivation or measurement.

## Gate 4 — Individual paper clearance

A paper is cleared only when:

1. its claim ledger is complete;
2. imported results have in-text citations;
3. every proof-bearing claim has a complete proof or exact dependency;
4. every numerical value regenerates from supplied source inputs;
5. covariance/uncertainty status is explicit;
6. the individual source package alone contains its evidence;
7. clean-room execution passes in the pinned environment;
8. a field-specific adversarial review is resolved.

## Gate 5 — Release reconstruction

Only cleared papers enter the next public release. A00 is rebuilt last from the cleared statuses. Zenodo and Git metadata are generated from the cleared release, not patched into the defective one.
